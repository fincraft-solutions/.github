# Marca Fincraft

O logotipo em `profile/assets/` foi fornecido pela equipe da Fincraft e foi incluído **sem redesenho**. A imagem `fincraft-avatar-github-512.png` é uma ampliação da imagem original de 150 × 150 px; não é um novo arquivo vetorial.

O fato de o repositório ser público não concede licença para reutilizar a marca, o símbolo, a identidade visual ou o nome em outros produtos. A licença MIT, caso escolhida para os projetos de software, não se aplica automaticamente à marca.

Para atualizar o avatar da organização, faça upload manual de `profile/assets/fincraft-avatar-github-512.png` em *Organization settings* do GitHub. A API de repositórios e o script de publicação não alteram automaticamente esse avatar.
